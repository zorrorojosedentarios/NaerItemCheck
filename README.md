# NaerItemCheck v1.5

**NaerItemCheck** es un addon avanzado de inspección de equipo para **World of Warcraft 3.3.5a (WotLK)**, diseñado específicamente para el servidor **NaerZone**. Permite verificar de forma rápida y visual si tu objetivo tiene equipados objetos específicos de las bandas **Icecrown Citadel (ICC)** y **Sagrario Rubí (SR)**.

---

## 🚀 Funcionalidades y Módulos

| Característica / Módulo | Descripción |
|---|---|
| **Base de datos de ICC y SR** | Cubre todos los jefes y abalorios/armas/objetos clave de dificultades 10N, 10H, 25N y 25H. |
| **Interfaz Premium** | Panel elegante de 600x500 con iconos detallados y códigos de color según el estado del objeto. |
| **Editor en Tiempo Real** | Permite agregar, editar o remover IDs de objetos en la base de datos directamente desde el juego con el botón ⚙️. |
| **Historial Persistente** | Guarda automáticamente las configuraciones e ítems añadidos entre sesiones. |
| **Acceso Rápido** | Botón en el minimapa para abrir/cerrar y soporte nativo para cerrar con la tecla Escape. |

> **Uso del color en la interfaz**: 
> * ⚪ **Gris**: Sin datos del jugador.
> * 🔵 **Celeste**: Solicitando datos al servidor...
> * 🟢 **Verde**: El jugador tiene el objeto equipado.
> * 🔴 **Rojo**: El jugador NO tiene el objeto equipado.

---

## 🛠️ Instalación

1. Descarga el addon.
2. Copia la carpeta `NaerItemCheck` en tu directorio `World of Warcraft\Interface\AddOns\`.
3. Asegúrate de que la carpeta se llame exactamente `NaerItemCheck`.
4. Actívalo en el menú de Addons al iniciar el juego o escribe `/reload` si ya estás dentro.

---

## 📖 Uso Rápido

* **`/nic`**: Abre o cierra la interfaz principal del addon.
* **Clic Izquierdo** en el botón del minimapa para abrir o cerrar el panel principal.
* **Shift + Clic** para arrastrar el botón del minimapa libremente.
* Haz clic en el botón de engranaje (⚙️) de la esquina superior para acceder al editor y modificar las IDs de los objetos a comprobar.
